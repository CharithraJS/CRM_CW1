# S&P 500 Market Analysis and Stock Segmentation

Coursework: 6BUIS017W — CRM & CM with Business Intelligence.

## Overview
Analysis of S&P 500 securities using historical weekly returns,
weekly beta and adapted Recency, Frequency and Monetary features.

Sources: Wikipedia S&P 500 constituents and Yahoo Finance.
Historical study period: 2021-01-01 to 2025-01-01

## Files
- CRM_CWK1_Stock_Analysis.ipynb: Full analysis notebook.
- requirements.txt: Recorded Python package versions.
- data/: Saved data snapshots, feature tables,
  cluster assignments and visualisations.
